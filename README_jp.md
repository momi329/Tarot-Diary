# Tarot Diary 🔮

占い・記録・オリジナルスプレッド設計（牌陣設計）機能を備えたタロットサービスです。

## Highlights

- TailwindCSS と React の useState を活用し、CSS Animation を手作業で実装。

  - 単に機能を提供するだけではなく、サービスを使う過程そのものを楽しめる UI / UX を意識して設計しました。

- ビジュアルデザインの経験を活かしたデザイン設計。

  - グラフィックデザインやパッケージデザインの経験を活かし、配色・レイアウト・ビジュアル構成にこだわりながら、統一感のあるプロダクト体験を目指しました。

- 常にユーザー視点でプロダクトを設計。
  - ユーザー同士が感想や体験を共有できるコミュニティ機能を実装し、継続利用やエンゲージメント向上を意識しました。

---

## Technical Features

### Home Page

- CSS Animation や Transition を活用し、没入感のあるトップページを実装。

### Divination

- React の useRef と Web API を利用し、ライブラリを使わずにカルーセル機能を実装。
- OpenAI API を活用して占い結果を自動生成。
- Unsplash API と連携し、ユーザーがテーマに合わせた背景画像を選択できるように実装。

### Spread Design

- Drag and Drop API を利用し、オリジナルスプレッドを自由に作成できる機能を実装。

### Record

- 占い結果や感情を記録できる記録機能を実装。

### Social Media

- データ取得時に Skeleton UI Loading を実装。
- ライブラリを使わず、占い記録を確認できるカレンダー機能を実装。
- Firebase の onSnapshot を利用し、リアルタイム更新を実現。
